# Student Management System

A simple Python application built for the Agile Software Development & DevOps
Lab experiment: study and implement the Agile software project lifecycle using
Jira, with GitHub version control and a GitHub Actions CI pipeline.

## Features

- Add and validate student records (name, roll number).
- Validate student email addresses.

## Run tests

```bash
pip install -r requirements.txt
python -m pytest -v
```
